# Digital Profit Review (digitalprofitreview.com)

Static site generated by `build.py` (Python 3 + Pillow). Vercel serves the generated HTML and auto-deploys every push to `main`.

## Add a new article (one file per post)
1. **Image:** put a portrait hero (about 900x1350) at `/workspace/src-jpg/` or anywhere you like, then create these three files:
   `assets/<category>/<name>-lg.webp` (900 wide), `<name>-sm.webp` (480 wide) and `<name>-og.jpg` (1200x630). The Pillow snippet is below.
2. **Products:** add every ASIN you use to `content/products.py` with its name, Amazon rating and rating count as checked today, and update `CHECKED`. Only list products that are in stock. Never add prices.
3. **Post file:** copy an existing file such as `content/home/gifts-for-new-homeowners.py` to `content/<category>/<slug>.py` and edit its `POST` dict:
   - `slug`, `title`, `seo_title` (60 characters or fewer), `desc` (150–160 characters), `image` (`assets/<category>/<name>.jpg`, the base name only), `image_alt`
   - `published` and `updated` (YYYY-MM-DD)
   - `intro` (a list of paragraphs)
   - `products`: a list of dicts with `asin`, `h2` ("Best for X: Product name"), `best`, `why` (paragraphs), `who`, `pros` and `cons`
   - `sections`: a list of `(heading, html)` for buying tips and similar content
   - `faqs`: a list of `(question, answer)`
   - `conclusion` and `related_text` (internal links)
4. Run `python3 build.py`. It prints each URL with its word count and reading time (aim for 1,200–1,800 words).
5. Commit and push to `main`.

The template adds the following automatically:
- the disclosure, table of contents and comparison table
- H2 product sections, pros and cons, and the "Check price on Amazon" buttons
- the FAQ, byline and dates, reading time and related posts
- the canonical URL, Open Graph and Twitter tags, and JSON-LD (BlogPosting, ItemList, FAQPage, BreadcrumbList)
- sitemap lastmod

Every Amazon link is `https://www.amazon.com/dp/<ASIN>?tag=hearthhaven0b-20` with `rel="sponsored nofollow noopener" target="_blank"`.

New category: add an entry to `CATEGORIES` in `build.py` and create `content/<key>/`.

Images snippet:
```python
from PIL import Image; im=Image.open(SRC).convert('RGB'); b='assets/home/my-post'
for w,k in ((900,'lg'),(480,'sm')): w=min(w,im.width); im.resize((w,round(im.height*w/im.width))).save(f'{b}-{k}.webp',quality=76)
W,H=im.size; ch=round(W*630/1200); t=(H-ch)//3; im.crop((0,t,W,t+ch)).resize((1200,630)).save(b+'-og.jpg',quality=82)
```

Rules: no fake ratings or reviews in schema, no invented prices, and do not hotlink Amazon product images.
